Each processing role walks its provider chain from top to bottom until one succeeds. Add your own entries to override the server default for that role only. Several keys for the same provider and model form a pool: keys rotate, a rate-limited key rests for 60 s, and a key that fails authentication is retired.

Your keys are stored only in this browser and sent with each request; the server does not save them. Every configured vendor receives session audio or transcripts, so review its data-handling terms first.
